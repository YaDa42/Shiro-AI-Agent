# \# Shiro AI 🤖

# 

# \## 🇬🇧 English

# 

# \*\*Shiro AI\*\* is an open-source AI agent written in Python. It can interact with computer interfaces and perform automated actions using an AI model.

# 

# \### Features

# \- Supports Groq and local Ollama models (depending on configuration).

# \- Configurable AI model and host.

# \- Adjustable maximum number of agent steps.

# \- Simple YAML configuration.

# \- Open-source Python code.

# 

# \### Project Files

# \- `agent.py` - Main agent code.

# \- `config.yaml` - Configuration settings.

# \- `requirements.txt` - Python dependencies.

# \- `README.md` - Project documentation.

# 

# \### Getting Started

# 1\. Download or clone this repository.

# 2\. Install dependencies:

# &#x20;  `pip install -r requirements.txt`

# 3\. Configure `config.yaml`.

# 4\. Run the agent:

# &#x20;  `python agent.py`
